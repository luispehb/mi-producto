Hap: una app para personas que viajan y quieren conocer gente en diferentes ciudades del mundo mientras hacen planes juntos.

## Reacción

Entendió: que es un sitio para conectar a viajeros solos según gustos y preferencias de actividades en la ciudad que esten visitando. Ofrece actividades para hacer.

No entendió: Si es gratis o no, Como se que es confiable y que la gente es real, Que garantias de seguridad tengo.

- Pensó que era una landing page de una consultora porque no tenía imágenes de nada.
- No entendió cómo funcionaba la app.
- Preguntó si había que pagar.
